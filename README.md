# FUSE Events ù Backend API

Express + MongoDB API for the FUSE events platform.

## Setup

```bash
cp .env.example .env
npm install
npm run seed    # clears DB + creates admin/agent accounts only (no demo events)
npm run dev     # http://localhost:5001
```

## Default credentials (after seed)

- **Admin:** admin@fuse.events / admin123
- **Seif:** seif@fuse.events / seif (username: `seif`)
- **Gate agent:** agent@fuse.events / agent123

Seed does **not** create events, artists, bookings, or tickets ó add those in admin.

## API

Base URL: `/api/v1`

- `GET /api/health` ù health check (used by Render)
- `POST /auth/login`, `/auth/register`, `GET /auth/me`
- `GET /events`, `/events/:slug`, `/characters`, `/content/home`
- `POST /bookings`, `POST /bookings/:id/confirm`
- `POST /tickets/scan` (gate agent)
- `/admin/*` ù admin CRUD (auth required)
- `/analytics/*` ù dashboards & CSV export

## Env vars

See `.env.example`. Note: macOS uses port 5000 for AirPlay ù local default is **5001**.

## Deploy (Render)

### Prerequisites

1. Push this repo to GitHub (including `render.yaml`).
2. Create a **MongoDB Atlas** cluster and a database user.
3. In Atlas ? Network Access, allow `0.0.0.0/0` (Render has dynamic IPs).
4. Copy the Atlas connection string as `MONGODB_URI` (`mongodb+srv://...`).

### Option A ù Blueprint (recommended)

1. Open: https://dashboard.render.com/blueprint/new?repo=https://github.com/seifasf/fuse-back
2. Fill secrets marked ùsync: falseù:

| Var | Value |
|-----|--------|
| `MONGODB_URI` | Atlas connection string |
| `ADMIN_SECURITY_KEY` | strong random admin key |
| `CLIENT_URL` | `https://your-app.vercel.app` (no trailing slash) |
| `API_PUBLIC_URL` | leave blank on first apply, then set to `https://fuse-api.onrender.com` (or your service URL) |

`JWT_SECRET` and `QR_SECRET` are auto-generated by the Blueprint.

3. Click **Apply** and wait for the deploy to go live.
4. Set `API_PUBLIC_URL` to the service URL if you left it blank, then redeploy (or update env + restart).
5. In Render ? service ? **Shell**, run once:

```bash
npm run seed
```

Then change the default admin/agent passwords.

### Option B ù Manual Web Service

- **Runtime:** Node
- **Build:** `npm ci --omit=dev`
- **Start:** `npm start`
- **Health check path:** `/api/health`
- Same env vars as above (`NODE_ENV=production`, `NODE_VERSION=20`)

### After deploy

- Smoke test: `GET https://<your-service>.onrender.com/api/health` ? `{ "status": "ok" }`
- Point the frontend `VITE_API_URL` at `https://<your-service>.onrender.com/api/v1`
- Free tier spins down after ~15 minutes idle (cold start on next request)

SMTP / WhatsApp / payment keys are optional until you enable those features.
